# CMCC

Official PyTorch implementation for the paper: **CMCC: Detecting cropland changes via cross-modal paired semantic maps and remote sensing imagery.**

> 🚧 **Status:** *This paper is currently under review at IEEE TGRS (Transactions on Geoscience and Remote Sensing). The full source code will be publicly released upon the acceptance/publication of the paper.*
